# climate-ocean-indices
Automated and reproducible collection, standardization and visualization of climate and oceanographic indices for research and higher education.

## Project status

Early development prototype.

## Principles

- Use authoritative institutional data sources.
- Preserve the original definition and units of each index.
- Do not recalculate an official index when an authoritative
  published product is available.
- Record source, retrieval date, methodology and processing steps.
- Separate scientific data processing from web visualization.
- Provide machine-readable and human-readable data products.

## Planned outputs

- CSV
- JSON
- MATLAB MAT files
- Interactive web visualizations

## Initial indices

- ENSO / RONI
- Southern Annular Mode (SAM)
- Madden-Julian Oscillation (MJO)
